How it works. The Lite option embeds a tiny poster; the game is fetched only when a visitor clicks Play — so a page carrying the embed stays fast. Direct loads the game as soon as the frame appears. Sound starts on the visitor's first click (browser autoplay rules). No SharedArrayBuffer / cross-origin-isolation headers are required, so the frame works on any site. Self-hosting? Set your Base URL and a direct link to your pop2-data.tar.gz above, and the snippet points at your copy (see SELF-HOSTING.md).
